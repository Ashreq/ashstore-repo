📖 About AshStore

AshStore is a personal repository for enhanced applications and custom builds.

The goal of AshStore is to provide a clean, organized, and regularly updated collection of applications with improved features and custom enhancements.

⸻

📲 Add AshStore

Add the following repository URL to your supported installer:

https://raw.githubusercontent.com/Ashreq/ashstore-repo/main/apps.json

After adding the repository, refresh your sources to view the latest available applications.

⸻

✨ Features

✅ Automatic app updates
✅ Clean app metadata management
✅ Version history tracking
✅ SHA256 file verification
✅ Automatic icon generation
✅ Detailed app descriptions
✅ Organized release management

⸻

🔄 Update System

AshStore uses an automated update system.

When a new release is published:

* App information is updated automatically
* New versions are added
* Icons are generated
* File hashes are calculated
* Repository metadata is refreshed
